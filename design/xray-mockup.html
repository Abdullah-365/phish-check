Find your email's source

  1. Open the email on a computer.
  2. Click ⋮ next to the reply arrow.
  3. Choose Download message. You get an .eml file.
  4. Drop that file anywhere on this page.

Rather copy and paste? Choose Show original instead, click Copy to clipboard, and paste it into the box.

  1. Open the email.
  2. Click ⋯ for more actions.
  3. Choose Save as to download an .eml file.
  4. Drop that file anywhere on this page.

Classic Outlook on Windows: drag the email from your inbox onto the desktop. That makes a .msg file, which works too.

  1. Select the email.
  2. Choose File then Save As…
  3. Set Format to Raw Message Source and save.
  4. Drop that file anywhere on this page.

Faster: drag the email from Mail straight onto your desktop, then onto this page.

  1. Open the email.
  2. Click ⋯ More.
  3. Choose View raw message.
  4. Select everything, copy it, and paste it into the box.
  1. Phone apps can't save an email's source. Open the same email on a computer instead.
